Tools

Computational pipelines in Google Colab and browser-based utilities for day-to-day laboratory work.

Structural Modeling

Protenix-v2

All-atom structure prediction for proteins, DNA, RNA, and small-molecule ligand complexes, with separate notebooks for single inputs and batch runs.

Colab (Single) ↗ Colab (Batch) ↗ GitHub ↗ Reference: ByteDance AI4Science, 2025

OpenDDE

Macromolecular complex modeling and binding interface prediction via Aureka Research's Open-Source Drug Design Engine, available for single runs and batch jobs.

Colab (Single) ↗ Colab (Batch) ↗ GitHub ↗ Reference: Aureka Research, 2026

Binder Design

RFdiffusion3

All-atom de novo protein binder design conditioned on target structures.

Open in Colab ↗ GitHub ↗ Reference: Krishna et al., 2025

BindCraft 2

End-to-end de novo protein binder design combining AlphaFold 2 gradient-based backbone generation, ProteinMPNN sequence design, and interface confidence filtering.

Open in Colab ↗ GitHub ↗ Reference: Pacesa et al., 2025

RFD4-Proteina

Joint sequence and all-atom structure co-design across proteins, nucleic acids, and modified residues for binder design, motif scaffolding, partial diffusion, and inverse folding.

Open in Colab ↗ GitHub ↗ Reference: Corley et al., 2026

Genome Annotation and Assessment

OrionGeno

Ab initio eukaryotic gene model prediction directly from genomic FASTA sequences.

Open in Colab ↗ GitHub ↗ Reference: Liu et al., 2026

Tiberius

End-to-end eukaryotic gene prediction combining convolutional and transformer layers with a differentiable hidden Markov model.

Open in Colab ↗ GitHub ↗ Reference: Gabriel et al., 2024

Helixer

Ab initio eukaryotic gene prediction across multiple lineage models, paired with gffread sequence extraction and BUSCO completeness checks.

Open in Colab ↗ GitHub ↗ Reference: Holst et al., 2025

Carbon-A

Eukaryotic gene prediction using the 1.2B-parameter Carbon-A DNA language model and a Viterbi gene-grammar decoder, outputting GFF3 models, coding-probability tracks, and BUSCO summaries.

Open in Colab ↗ GitHub ↗ Reference: HuggingFaceBio, 2026

BUSCO

Completeness assessment for proteomes, genome assemblies, and transcriptomes against OrthoDB lineages across single files or batches, with summary tables and stacked-bar plots.

Open in Colab ↗ GitHub ↗ Reference: Manni et al., 2021

Lab Workflows

cloneBench

Interactive bench planner for Golden Gate and Type IIS restriction-ligation cloning. Computes pipetting volumes from plasmid concentrations and molar ratios, audits internal restriction sites, pools master mixes, and exports run sheets to Excel or CSV.

Open cloneBench ↗ GitHub ↗

prepBench

Interactive bench calculator for bacterial culture dilution and OD600 normalization across single strains or multi-strain co-cultures, with construct tracking, dead-volume allowances, and exportable run sheets.

Open prepBench ↗ GitHub ↗
