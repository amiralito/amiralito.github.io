Structural Modeling

Protenix-v2

Biomolecular Structure Prediction · Proteins, Nucleic Acids & Small Molecules

Google Colab notebooks providing single-sequence and high-throughput batch structure prediction powered by ByteDance's Protenix-v2, an open-source all-atom biomolecular modeling system. Predicts structures of proteins, DNA, RNA, and small-molecule ligand complexes.

Google Colab Notebooks: These are Google Colab notebooks providing easy, browser-based cloud GPU access to Protenix-v2 without requiring local installation or specialized hardware.
Citation & Reference ByteDance AML AI4Science Team. Protenix-v2 Technical Report (2026); bioRxiv (2025) doi:10.1101/2025.01.08.631967.
Open in Colab (Single) Open in Colab (Batch) GitHub Repository

OpenDDE

Drug Design Engine · Macromolecular Modeling & Structure Generation

Google Colab notebooks providing single-run and batch modeling via OpenDDE (Open-Source Drug Design Engine) by Aureka Research, tailored for macromolecular complex modeling, binding interface prediction, and structure-based discovery workflows.

Google Colab Notebooks: These are Google Colab notebooks providing easy, browser-based cloud GPU access to OpenDDE without requiring local installation or complex dependencies.
Citation & Reference Aureka Research. OpenDDE: Open-Source Drug Design Engine (2026). Available on GitHub: github.com/Aureka-Research/OpenDDE.
Open in Colab (Single) Open in Colab (Batch) GitHub Repository

Binder Design

RFdiffusion3

De Novo Binder Design · All-Atom Biomolecular Interactions

Google Colab pipeline implementing RFdiffusion3 for de novo design of high-affinity protein binders against specified molecular targets. Generates complementary binder backbones conditioned on target structures with full atom-level accuracy.

Google Colab Notebook: This is a Google Colab notebook providing easy, browser-based cloud GPU access to RFdiffusion3 without requiring local installation or cluster setup.
Citation & Reference Krishna R, et al. De novo Design of All-atom Biomolecular Interactions with RFdiffusion3. bioRxiv (2025) doi:10.1101/2025.09.18.676967.
Open in Colab GitHub Repository

Genome Annotation

OrionGeno

Deep Learning Genome Annotation · Ab Initio Gene Model Prediction

Google Colab notebook deploying OrionGeno for accurate ab initio eukaryotic gene prediction directly from genomic FASTA sequences. Utilizes modern deep learning to resolve exon-intron boundaries and complex genomic architecture.

Google Colab Notebook: This is a Google Colab notebook providing easy, browser-based cloud GPU access to OrionGeno without requiring local installation or environment configuration.
Citation & Reference Liu L, et al. Advancing ab initio genome annotation with OrionGeno. bioRxiv (2026) doi:10.64898/2026.04.26.720859.
Open in Colab GitHub Repository

Tiberius

End-to-End Deep Learning & HMM · Eukaryotic Gene Finding

Google Colab notebook running Tiberius, an end-to-end gene prediction framework that couples convolutional neural networks and transformer layers with a differentiable Hidden Markov Model (HMM) for rapid, accurate eukaryotic genome annotation.

Google Colab Notebook: This is a Google Colab notebook providing easy, browser-based cloud GPU access to Tiberius without requiring local compilation or dependencies.
Citation & Reference Gabriel L, Becker F, Hoff KJ, Stanke M. Tiberius: end-to-end deep learning with an HMM for gene prediction. Bioinformatics 40(12):btae685 (2024) doi:10.1093/bioinformatics/btae685.
Open in Colab GitHub Repository

Lab Workflows

cloneBench

Assembly Planner · Golden Gate & Restriction-Ligation

An interactive planner for Golden Gate and Type IIS restriction-ligation cloning. Calculates exact pipetting volumes for plasmid preps based on measured concentrations and molar ratios relative to the destination vector.

Features automated Type IIS recognition site auditing across circular sequences, water make-up calculations, shared master mix pooling with configurable excess, part inventory tracking across multi-tube runs, and a quick dilution calculator (C1·V1 = C2·V2).

Molar Dosing Type IIS Site Audit Master Mix Optimizer Part Usage Tracking Excel (.xlsx) & CSV Export Offline Safe
Launch cloneBench GitHub Repository

prepBench

Dilution Planner · Bacterial Culture & OD600 Normalization

An interactive bench tool designed for bacterial dilution planning and OD600 normalization. Calculates exact neat culture and buffer volumes needed to normalize bacterial suspensions to target densities.

Supports single-strain dilutions and multi-strain co-culture combinations, tracks construct metadata (strains, plasmids, tags, antibiotics, stock locations), accounts for pipetting dead volume, and exports formatted run sheets for the bench.

OD600 Normalization Bacterial Co-Cultures Construct Library Neat Culture Volume Tracking Bench Run Sheets Excel (.xlsx) & CSV Export Offline Safe
